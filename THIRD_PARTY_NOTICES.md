[Publisher source](https://doi.org/10.1371/journal.pone.0147073). The source carries a Creative Commons Attribution notice. ## Dataset

Moreno-Sánchez, I.; Font-Clos, F.; Corral, Á. *Word frequencies from Project Gutenberg English texts*, [Figshare v3](https://doi.org/10.6084/m9.figshare.1515919.v3), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). File 2284750, PG_English_wordfreqs.zip. The raw archive is obtained on demand; derived input metadata, model fits, simulation results and aggregates are included. No Gutenberg book texts are redistributed. The raw frequency values were not modified or filtered for the original analysis. Repository source records and checksums identify the release used.
